# DIE TOMORROW 明日再死 —— 一个用 AI 协作开发的单文件 FPS 范例工程

整个游戏是**一个 HTML 文件**：地图、贴图、人物、武器、音效全部由代码在运行时生成，没有任何外部素材，双击即可在浏览器里玩。
全部代码由 Claude Code 根据自然语言需求编写、自测、迭代。

## 直接玩

| 文件 | 说明 |
|---|---|
| `die-tomorrow.html` | 最新版 **DIE TOMORROW 明日再死**（v2.2），当前战役：潮汐断点 OPERATION TIDEBREAK |
| `neon-bunker.html` | 第一版原型 **NEON BUNKER**（v1.0） |

操作：WASD 移动 · Shift 冲刺 · C 蹲伏 · Z 匍匐 · Space 跳跃 · 左键射击 · 右键瞄准 · R 换弹 · 1/2 切枪 · E 长按交互 · Esc 暂停

## 版本迭代（releases/）

每个版本都保存了当时的成品 HTML 和自动化测试截图，可以随时打开老版本或重新截图。

| 版本 | 内容 |
|---|---|
| `v1.0-neon-bunker` | 霓虹地堡：随机地图、三种敌人、波次生存、小地图 |
| `v2.0-tidebreak-方块人` | 重做为写实港口：程序化 PBR 贴图、天空/海面/体积光、后处理、任务流程（切断中继站 → 撤离）。人物还是方块 |
| `v2.1-tidebreak-人物细节与掩体` | 人物重做（头盔/护目镜/战术背心/背包/关节四肢/三兵种外观）；敌人会奔跑、蹲姿射击、找掩体躲藏并探头；玩家新增匍匐与潜行 |
| `v2.2-die-tomorrow-定名` | 游戏定名 **DIE TOMORROW 明日再死**；TIDEBREAK 潮汐断点降为战役名 |

给老版本重新截图：`releases/shot.sh v2.0-tidebreak-方块人 /tmp/out`

## 工程结构

```
v2/src/        源码，按模块拆分（00-head … 11-main）
v2/build.sh    语法检查 + 拼接成单个 HTML
v2/test/       无头 Chrome 自动化测试（静音）：play.mjs 通关冒烟测试，models.mjs 人物特写
vendor/        three.js r128（构建时内联）
src/ test/     v1 的源码与测试
```

## 这个范例体现的 AI 用法

1. **自然语言提需求**：“做一款 HTML 的第一人称射击游戏”“人物没细节”“有奔跑、跳跃、匍匐、躲藏之类的动作吗”。
2. **AI 自己验证**：每次改动后用无头浏览器实际开局、走动、开火、通关并截图，看图发现问题再改（例如发现瞄具挡视野、测试等待时间不对）。
3. **跨会话续作**：v2 是在上一次会话做到一半的基础上，读懂已有模块后补完剩余 6 个模块。
4. **版本可追溯**：每个里程碑留存成品与截图，便于展示前后对比。
